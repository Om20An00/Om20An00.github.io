event-driven-notification-system
healthy

An asynchronous notification service built around Kafka producers and consumers, designed to survive the failure modes that actually happen in production: idempotent producers so retries don't cause duplicate sends, and a dead-letter-queue-backed retry path so a failing consumer doesn't take down the pipeline. Fully instrumented with a Prometheus + Grafana observability stack and packaged for Kubernetes deployment.

A distributed URL shortener built in Go, with Redis in front for low-latency lookups and PostgreSQL underneath for durable persistence. Deployed across multiple replicas on Kubernetes with a full CI/CD pipeline through GitHub Actions, and the same Prometheus/Grafana observability approach carried over from the notification system — because a shortener that silently drops redirects is worse than one that's slow.

healthy

A retrieval-augmented generation platform that lets teams ask natural-language questions across their own internal documents instead of searching for them.
